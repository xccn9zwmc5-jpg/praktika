Веб-приложение «Такси» — это удобный сервис для автоматизации работы диспетчера такси. Программа позволяет быстро оформлять новые поездки, автоматически рассчитывать стоимость по разным тарифам и вести учет заказов.

Что умеет приложение:
• Регистрировать поездки: Диспетчер вводит имя пассажира, адреса («Откуда»/«Куда») и расстояние.
• Рассчитывать стоимость: Система сама считает итоговую цену на основе пройденных километров и выбранного класса (Эконом, Комфорт или Бизнес).
• Назначать водителей из БД: Список доступных сотрудников с их реальным рейтингом и марками автомобилей загружается напрямую из базы данных SQLite.
• Отслеживать активный заказ: Текущая поездка сразу выводится на экран в блок «Архив расчетов» со статусом «В ПРОЦЕССЕ».
• Завершать заказы: По нажатию одной кнопки текущий рейс скрывается с экрана, сохраняясь при этом в истории базы данных.

Техническая часть:
Программа написана на языке Python с использованием веб-фреймворка Flask и встроенной базы данных SQLite 3. При первом запуске приложение само создает файл базы данных и наполняет его стартовым списком водителей.
